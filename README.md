## 🤖 Agent-native work

### [Thios](https://thios.co): one source of truth, six surfaces

Open-hardware modular shelters, designed by one person and kept consistent by agents.

- **`DESIGN.md` is the spine:** canonical rules plus an Agent Prompt Guide that agents read on every task.
- **212 W3C design tokens** feed production CSS on 4 sites, a live component demo, Figma, and a
  parametric Onshape CAD model.
- **Agents enforce it:** drift audits flag mismatches with `file:line` citations. Published as a
  Claude Skill, [`audit-design-token-drift`](https://github.com/peterbartsch/AgentDrift).
- **[A pre-registered benchmark](https://thios.co/design-system-bench.html)** on whether the agent
  infrastructure actually works. The lean Claude Skill beat the verbose one.

### [this trip, btw](https://thistripbtw.us): a product with agents as first-class users

A shareable trip map an AI assistant can build and a person can open. No account, no ads, nothing invented.

- **Agents can't sign up or pay, so the product needs neither.** The trip rides in the link itself.
- **A full agent layer:** link format, hosted MCP endpoint, a zero-dependency
  [MCP server](https://github.com/peterbartsch/thistripbtw-mcp) and an installable Skill, checked
  byte-for-byte so they can't drift.
- **A written rule for agents:** *"We record; we don't verify."* Never invent a flight number.
- Open beta, in use on real trips.
